# Slime Throw - Monetização

A pretensão é o jogo ser gratuito, mas tendo que infelizmente colocar anúncios para conseguir sua monetização. Oferecendo uma versão sem anúncios por um preço camarada. Também está sendo cogitado uma ideia de haver um modo multiplayer, e com isso um passe de batalha para poder customizar o seu slime.
